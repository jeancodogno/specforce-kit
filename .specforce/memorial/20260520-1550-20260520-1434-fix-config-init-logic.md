# Idempotent Initialization Checks

CLI commands that rely on directory structure (like init or update flows) must idempotently guarantee the existence of essential configuration files (e.g., config.yaml) early in their execution flow. Relying on path-specific logic (e.g., separating 'new init' vs 'update') can lead to inconsistent state if a user manually creates partial structures.
