# Passive vs Active Agent Intelligence

Agents in exploratory or creative phases (Discovery) should adopt a Passive/Advisory intelligence model. Mandatory tool gates (like ask_user) should be avoided in favor of informative text recommendations, allowing the user to drive state transitions. This prevents cognitive load and workflow friction.
