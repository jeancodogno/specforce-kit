# Affinity-Based Lazy Loading for Domain Context

Implemented a two-tier documentation hierarchy (Global Constitution + Module Manifests) with a surgical 'Lazy Load' protocol. Agents are instructed to check for directory/feature name affinity before reading domain-specific manifests, preventing context bloat while preserving deep domain knowledge.
