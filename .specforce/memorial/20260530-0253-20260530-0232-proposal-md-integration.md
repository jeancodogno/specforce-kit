# Formalized Discovery-to-Planning Proposal Protocol

Implemented the 'Proposal Protocol' in spf.discovery. This allows agents to formalize research into a proposal.md file within a surgical mutation exception (requires user confirmation). The spec status now automatically includes these auxiliary files in the context_files array, ensuring downstream planning agents (spf.spec) have mandatory access to the research intelligence.
